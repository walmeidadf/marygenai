# Ontology

This folder stores versioned ontology artifacts for the project.

Starting scope:

- study/publication;
- clinical trial record;
- drug interaction document;
- medical condition;
- compound/cannabinoid;
- terpene;
- organ system;
- route of administration;
- dosing/protocol;
- human review.

Private legacy vocabularies remain under ignored `temp/legacy/` paths and are
not distributed with the repository. Reviewed, license-compatible ontology
artifacts may be added here gradually with explicit source provenance and
versioning.
